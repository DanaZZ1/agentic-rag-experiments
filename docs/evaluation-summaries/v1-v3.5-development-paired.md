# Sanitized V1 vs V3.5 Development Evaluation Summary

This report retains aggregate operational outcomes only. It does not contain questions, answers, document text, citations, source paths, or raw traces.

## Observed aggregate outcomes

| Measure | V1 | V3.5 |
|---|---:|---:|
| Final responses | 20 | 1 answered, 12 not_in_corpus, 7 execution_failed |
| Model calls | 22 | 29 |
| Tokens reported | 12,237 | 68,930 |

These are measurements from one paired run on the frozen 20-question development selection. The token count is reported as captured by that run; it should not be interpreted as a per-question cost comparison without the underlying accounting details.

## Interpretation limits

- The evaluation's exact-match scorer is not a valid semantic accuracy metric.
- The development set did not have independent human semantic validation.
- No blinded manual review result is available.
- The outcome counts describe execution status, not answer correctness.
- The V3.5 targeted reliability repair was developed after this run and has not been retested with a real model.
- These observations do not demonstrate that V3.5 improves end-to-end answer quality over V1.
